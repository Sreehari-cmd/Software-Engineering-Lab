## How to use the board

1. Keep tasks in **Todo** until work begins.
2. Move a task to **In Progress** when actively working on it.
3. Move it to **Done** only after its deliverable is completed and checked.
4. Add screenshots, diagrams, test evidence, or relevant notes to the matching issue.

## Completion evidence

For each task, attach or link the actual output. Examples include diagram files, prototype screenshots, source code, test cases, test results, and the final report. Do not treat an issue's movement on the board as a substitute for the deliverable itself.
