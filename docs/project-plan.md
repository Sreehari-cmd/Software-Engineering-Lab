## How to use the board

1. Keep tasks in **Todo** until work begins.
2. Move a task to **In Progress** when actively working on it.
3. Move a task to **Done** only after its deliverable is completed and checked.
4. Attach screenshots, files, test evidence, or notes to the matching issue using **Add artifact** where available.

Only mark work as complete after the actual task has been done.
