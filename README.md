# Online Food Delivery App

A Software Engineering Lab project developed as part of the B.Tech Computer Science and Engineering programme at Jawaharlal College of Engineering and Technology (JCET).

## Project overview

The Online Food Delivery App is intended to help customers find restaurants, view menus, place food orders, make payments, and track deliveries. The system also supports restaurant staff and delivery partners in handling orders.

## Main user roles

- **Customer:** Creates an account, searches restaurants and food, manages a cart, places orders, pays online, tracks orders, views order history, and rates completed orders.
- **Restaurant staff:** Views incoming orders, accepts orders, and updates preparation and order status.
- **Delivery partner:** Views assigned deliveries and updates delivery progress.

## Main features

- User registration and login
- Restaurant and food search
- Menu, price, and availability display
- Cart management
- Order placement and checkout
- Online payment and payment-status recording
- Order-status notifications and delivery tracking
- Order history and ratings
- Role-based order updates
